# AI 대화 장기기억 앱 — 설계 문서 (가칭: AI 기억장)

작성일: 2026-11-21 · 상태: 검토 반영 완료(사용자 승인 대기)

## 1. 의도와 이유

- 사용자는 EPC 회사의 AI 활용 기획자로, 매일 Claude·ChatGPT(개인 계정)와 많은 대화를 나눈다.
- 대화에서 얻은 **업무 개념·기술 지식**이 머리에 남지 않는다. AI가 다 정리해 주니 "외울 필요 없음"으로 처리되는 인지 오프로딩이 원인으로 보인다.
- 목표는 "잘 보관하는 앱"이 아니라 **"다시 꺼내게 만드는 앱"**이다. 정리 노트는 필요하지만, 먼저 떠올리고 나서 확인하는 **해설지** 역할을 한다.

## 2. 목표 / 비목표 / 실패 조건

**목표**
- 대화를 마칠 때 한마디로 핵심 개념이 앱에 저장된다.
- 비슷한 질의응답은 **하나의 개념 노트로 합쳐져** 복습량이 개념 수에 비례한다.
- 출퇴근 지하철(폰, 한 손)과 자기 전(폰, 조용함)에 하루 3분 안팎으로 복습한다.
- 떠올리기 → 해설 확인 → 채점 → 간격 반복.

**비목표 (지금 안 함)**
- 앱스토어용 정식 앱, 홈 화면 위젯 (나중에 검토)
- 여러 사람이 쓰는 서비스, 팀 공유
- 결정 기록·업무 일지 (이번엔 지식만)
- 대화 기록 실시간 자동 수집 (공식 경로가 없음, 아래 4절)

**실패 조건 (기능은 돌아가도 실패)**
- 카드·개념이 너무 많이 쌓여 밀린 숙제가 되는 것
- 저장 과정이 번거로워 2주 안에 안 쓰게 되는 것
- 비슷하지만 다른 개념(예: P&ID / PFD)을 잘못 합쳐 헷갈림을 굳히는 것
- 해설을 먼저 보게 만들어 "읽기 앱"이 되는 것

## 3. 제약

- 아이폰 사용. **홈 화면에 추가한 웹앱(PWA)** 으로 동작하며, 알림은 iOS 16.4+ 홈 화면 앱 웹 푸시를 쓴다.
- 데이터는 클라우드(폰·PC 어디서나). 사용자 1명 전용, 본인 로그인 필요.
- 회사 정보 저장은 사용자가 허용함. 다만 NDA 위험이 있어 **"발주처·프로젝트명 자동 가리기" 스위치**를 둔다(기본 꺼짐).
- Claude·ChatGPT의 대화 기록을 정기적으로 가져오는 공식 API나 MCP는 없다(2026-11 조사). 비공식 쿠키 방식은 쓰지 않는다.
- 운영비는 월 몇천 원 이내(유료 AI API). 그 외 인프라는 무료 요금제.

## 4. 검토한 방법과 선택

| 방법 | 장점 | 단점 | 결과 |
|---|---|---|---|
| **A. PWA + Supabase + AI + MCP 통로** | 빠른 제작, 심사 없음, 폰·PC 공용, 같은 저장소의 '말해영어' 앱에서 검증된 조합 | 아이폰 알림이 정식 앱보다 덜 안정적, 위젯 불가 | **선택** |
| B. 정식 앱 (Expo 등) | 알림·위젯·음성이 매끄러움 | 기간 2~3배, 애플 비용과 심사 | 나중에. 습관이 붙고 알림·위젯이 아쉬울 때 A의 서버를 그대로 쓰며 전환 |
| C. Notion + Anki + Claude 프로젝트 | 만들 것이 거의 없음 | 자동 합치기·AI 채점이 안 되고, 앱 두 개를 오가야 함 | 탈락 |

수집 방식 검토: 공식 내보내기 ZIP만 쓰면 수동이고 느리다(ChatGPT는 며칠 걸리기도 함). 비공식 스크립트는 약관 위반·고장 위험이 있다. 그래서 **AI가 대화 끝에 MCP로 앱에 넣어주는 방식**을 주 경로로, ZIP은 과거분 일괄 가져오기 보조 경로로 쓴다.

## 5. 정해진 설계

### 5.1 데이터 구조 (3단계)
```
분야 (예: AI 활용, 프로젝트 관리, 데이터)
 └─ 개념 노트 — 해설지. 질의응답이 들어올 때마다 보강됨, 출처 대화 기록 유지
     └─ 질문 여러 개 — 설명형 / 상황 적용형(EPC 업무 상황) / 비교형
```
- 비슷한 개념끼리는 "헷갈림 짝"으로 연결하고, 짝마다 **비교 질문**("A와 B의 차이는?")을 만든다.
- **복습 일정은 개념 단위로** 관리한다. 복습 때 그 개념의 질문 중 하나를 돌아가며 낸다.

### 5.2 수집 흐름
1. Claude.ai / ChatGPT에 이 앱의 MCP 서버를 커스텀 커넥터로 연결한다.
2. 대화 끝에 "기억장에 저장해"라고 하면, 대화 중인 AI가 핵심 개념 후보(대화당 **최대 3개**)를 정리해 MCP 도구로 보낸다(제목, 해설 노트, 질문 2~3개, 분야 제안).
3. 서버가 기존 개념과 비교(임베딩 유사도)해서 "기존 ○○에 합치기 / 새 개념 / 헷갈림 짝으로 연결" 중 하나를 제안한다.
4. 앱의 **받은함**에서 후보마다 탭 한 번으로 확정한다(합치기 / 새로 / 버리기). 확정 전에는 복습에 들어가지 않는다.
5. 보조 경로: 공식 내보내기 ZIP(conversations.json)을 올리면 대화 목록에서 골라 같은 흐름으로 후보를 만든다.

### 5.3 복습
- **빠른 모드(지하철):** 질문 → 속으로 떠올리기 → 해설 보기 → "알았음 / 애매 / 몰랐음" 한 번 누르기. 한 손, 큰 버튼.
- **깊은 모드(자기 전):** 글이나 음성으로 답하면 AI가 해설 노트와 비교해 채점한다("핵심 3개 중 2개, 빠진 것: ○○"). 결과를 알았음/애매/몰랐음으로 바꿔 일정에 반영한다. 다크 모드.
- 해설은 **답을 시도한 뒤에만** 열린다(빠른 모드에서는 "떠올렸다" 버튼을 누른 뒤).
- 간격 반복: 기존 '말해영어' 앱의 단계식 간격(1일 → 3일 → 1주 → 2주 → 1달 → 2달 → 4달)을 바탕으로, 틀리면 앞 단계로 돌린다.
- 하루 목표 기본 5개념(설정으로 변경 가능). 밀려도 하루 상한을 넘겨 내지 않는다.
- 알림: 출근·퇴근·취침 전 시간대(사용자 설정)에 "오늘 복습 N개".

### 5.4 노트 보기
- 분야별·검색으로 개념 노트를 바로 읽을 수 있다(급할 때 찾아보는 용도). 복습 화면과 분리한다.

## 6. 내가 정한 것 (사용자 확인 필요)

- **AI 비용 구조 (사용자 결정: 유료 API):** 카드 내용은 대화 중인 Claude/ChatGPT가 만든다(구독 안에서 해결). 서버 쪽 AI(합친 노트 초안, 채점, 비교 질문)는 **유료 Claude API**를 쓴다. API로 보낸 데이터는 기본적으로 학습에 쓰이지 않는다. 비용은 가벼운 모델 기준 월 몇천 원 이내를 예상한다. 무료 등급 AI나 임베딩 서비스로는 노트 내용을 보내지 않는다(내용이 학습에 쓰일 수 있음). 임베딩은 유료 서비스 또는 Supabase 내장 모델 중 한국어 품질을 확인해서 고른다.
- **ChatGPT (Plus):** 개발자 모드의 MCP 쓰기 기능을 Plus에서 쓸 수 있는지 OpenAI 문서끼리 서로 다르게 적혀 있다(2026-11 확인). 구현 첫 단계에서 실제 계정으로 확인하고, 막히면 "대화 붙여넣기" 대비책을 ChatGPT의 기본 경로로 삼는다. Claude.ai를 주 경로로 먼저 만든다.
- **기술:** Vite + TypeScript PWA, Supabase(Postgres + pgvector, Edge Function 하나에 앱 API와 MCP 엔드포인트), 웹 푸시. '말해영어'의 로그인·푸시·간격 반복 코드 패턴을 참고하되 **코드와 DB는 분리**한다(새 Supabase 프로젝트 또는 별도 스키마).
- **위치:** 저장소의 `ai-memory/` 폴더. 기존 게임 앱과 빌드·배포를 섞지 않는다.

## 6-1. 검토 후 내가 정한 세부 규칙 (사용자 확인 필요)

- **합치기 시 노트 처리:** 서버 AI가 기존 노트와 새 내용을 합친 **새 노트 초안**을 만들고, 받은함에서 바뀐 부분을 보여준 뒤 확정한다. 이전 판은 버전 기록으로 남긴다. 단순히 덧붙이지 않는다(노트가 비대해지는 것 방지).
- **합치기 시 복습 일정:** 단계는 유지하고, 다음 복습만 **하루 안으로 당긴다**(새로 추가된 내용을 한 번 꺼내보게).
- **간격 규칙(개념 단위):** 새 개념의 첫 복습은 **같은 날 취침 전 또는 다음 날 출근길**이고, 이후 1일 → 3일 → 1주 → 2주 → 1달 → 2달 → 4달(마스터). 알았음이면 다음 단계, 애매면 단계 유지에 간격 절반, 몰랐음이면 **두 단계 뒤로**. 개념은 단어보다 크기 때문에 처음으로 되돌리지 않는다.
- **헷갈림 짝:** 비교 질문은 **독립된 복습 단위**로 일정을 따로 가진다. 짝을 확정할 때 서버 AI가 질문을 만든다. 채점은 짝 일정에만 반영한다.
- **음성:** 1차 버전은 글 입력만 지원한다. 음성은 아이폰 키보드의 받아쓰기(마이크) 버튼으로 대신한다. 홈 화면 웹앱의 음성 인식은 불안정하기 때문이다.
- **ZIP 가져오기:** 2차 버전으로 미룬다. 그때 Claude와 ChatGPT 내보내기 형식을 모두 지원하고, 서버 AI가 후보를 만들되 무료 한도를 고려해 하루 처리량을 제한한다.
- **가리기 스위치:** 사용자가 직접 관리하는 **"가릴 이름 목록"**(발주처, 프로젝트명)을 기준으로, **저장할 때** "발주처 A", "프로젝트 B"처럼 바꿔 넣는다. AI가 알아서 찾게 하면 놓치는 경우가 많아, 목록 방식이 더 확실하다.
- **Supabase:** '말해영어'와 **별도의 새 프로젝트**로 만든다(무료 요금제는 활성 프로젝트 2개까지). 로그인, 열쇠, DB가 섞이지 않게 하기 위해서다.
- **ChatGPT에서 저장이 막힐 때의 대비책:** 받은함에 "대화 붙여넣기" 칸을 둔다. 붙여넣은 대화에서 서버 AI가 후보를 만든다.

## 7. 빌더에게 맡기는 것

- MCP 엔드포인트 인증 방식(Claude.ai·ChatGPT 커스텀 커넥터가 지원하는 범위 안에서, 본인만 쓰는 안전한 방법)
- 임베딩 모델, 합치기 유사도 기준값
- 화면 세부 디자인, 배포 주소
- ZIP 가져오기의 대화 선택 UI
