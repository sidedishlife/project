# 말해영어 — 내 말을 영어로, 잊기 전에 다시

한국어로 쓰거나 말하면 원어민이 실제로 쓰는 영어 표현을 만들어 주고,
**망각곡선(간격 반복)** 에 맞춰 복습 게임으로 외우게 하는 휴대폰용 웹앱(PWA)입니다.

## 기능
- **표현 만들기**: 한국어 입력/음성 입력(🎙️) → 대표 표현 + 대안 표현 + 뉘앙스 설명 + 단어장 (Claude API)
- **20회 듣기**: ▶ 한 번씩 또는 🔁 연속 재생(재생 사이 1.2초 따라 말하기 틈), 🐢 느리게, 진행 링으로 횟수 표시
- **단어 탭 사전**: 문장 속 단어를 누르면 뜻·발음기호·품사·예문. 목록에 없는 단어는 문맥 기준으로 바로 찾아 카드에 저장
- **망각곡선 복습**: 10분 → 1일 → 3일 → 1주 → 2주 → 1달 → 2달 → 마스터. 틀리면 처음부터
- **게임 요소**: 회상(직접 말하기)/단어 배열/듣고 고르기 3가지 모드, 콤보·XP·레벨·연속 학습일
- 데이터는 기기 브라우저에 저장, JSON 백업/복원

## 실행
```bash
npm install
npm run dev      # 같은 Wi‑Fi의 휴대폰에서 표시되는 Network 주소로 접속
npm test
npm run build    # dist/ 를 아무 정적 호스팅에 올리면 됨
```
`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml` 이 GitHub Pages로 배포합니다
(저장소 Settings → Pages → Source를 "GitHub Actions"로 설정, 비공개 저장소는 유료 플랜 필요).

휴대폰에서 연 뒤 **홈 화면에 추가**하면 앱처럼 실행됩니다. 앱의 설정 탭에 Anthropic API 키를 입력하세요.

## 구조
| 파일 | 역할 |
|---|---|
| `src/api.ts` | Claude API 호출(구조화 출력 JSON, 거절 시 서버측 fallback) |
| `src/srs.ts` | 망각곡선 복습 간격 계산 (+ `srs.test.ts`) |
| `src/speech.ts` | 브라우저 내장 TTS(영어 읽기) / STT(한국어 음성 입력) |
| `src/store.ts` | localStorage 저장, 연속 학습일, 백업 |
| `src/main.ts` | 화면·게임 로직 |

## 알려진 제약
- API 키가 브라우저에 저장되는 **개인용 구조**입니다. 여러 사람에게 배포하려면 키를 숨기는 서버(프록시)가 필요합니다.
- 음성 입력은 Chrome(안드로이드)·Safari(iOS) 지원 범위에 따릅니다. 미지원 시 키보드 마이크 받아쓰기를 쓰면 됩니다.
- 웹앱이라 "복습할 시간" 푸시 알림은 없습니다(앱을 열면 홈에서 복습 개수 표시).
